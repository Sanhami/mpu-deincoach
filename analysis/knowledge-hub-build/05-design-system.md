# 05 — Design System

Brand tokens: ink `#282828`, signal yellow `#F8E030`, warm paper `#F7F6F1`, warm white `#FFFEF9`, muted ink `#68675F`, line `#D8D5CA`. Yellow is limited to rules, focus, small shapes and contained transition cards.

The system uses an editorial serif for display/reading hierarchy and system sans-serif for navigation, labels and metadata. Reading width is 720 px. Cards communicate structure; none exists only for decoration.

Responsive behavior is mobile-first at the component level with major layout transitions at 980, 700 and 390 px. Visual QA confirmed no horizontal overflow at 320, 375, 390, 430, 768 and 1440 px after two CSS fix loops.

Accessibility: skip link, landmarks, semantic headings, labelled search, disclosure-based FAQ, visible focus, minimum 44 px menu control and 52 px search control, reduced-motion override, high-contrast text and an accessible mobile navigation state.

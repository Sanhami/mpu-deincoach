- Lighthouse accessibility: 100 on both tested routes.
- One H1 and one each of header, navigation, main, and footer were found on the homepage.
- No empty links were found.
- No image without alternate text was found.
- The first keyboard focus target is `Zum Inhalt springen`, with a visible 3 px yellow outline.

- Keyboard focus on interactive controls uses a visible 3 px yellow outline.
- Mobile navigation and FAQ disclosure state changes were verified.

No automated or manual blocker was found in this staging pass. This does not replace a specialist conformance audit.

# Review approval form

Use one form per reviewer and article. This is internal documentation, not a public signature workflow.

```text
Article:
Route:
Content version / commit:

Reviewer:
Role / qualification:
Relevant competence and current practice:
Conflict disclosure:
Review date:

[ ] Fachlich approved
[ ] Approved with required changes
[ ] Not approved

Reviewed sections / claim IDs:

Required corrections:

Sources checked, including version/date:

Claims requiring qualification or removal:

Review scope and explicit exclusions:

Required follow-up reviewer, if any:

Next review date or trigger:

[ ] I authorize this reviewed version for APPROVED_NOINDEX.
[ ] I authorize this reviewed version for APPROVED_PUBLIC, subject to every other required gate.
[ ] I authorize Article schema for this reviewed scope after APPROVED_PUBLIC.
[ ] I authorize FAQ schema for reviewed FAQ items after APPROVED_PUBLIC.

Reviewer confirmation:
Name:
Date:
Confirmation method / evidence location:
```

An editor records the final state only after all required forms refer to the same content version. Silence, a meeting attendance, or a reviewer name without a decision is not approval.
